# 실무 프로젝트 목록

## 실무 프로젝트 개요
실무 프로젝트는 학생이 기업 협력사 또는 교내 과제를 통해 실제 서비스를 개발하는 교육과정이다.
학년별로 난이도와 참여 방식이 다르다.

## 학년별 실무 프로젝트

### 1학년
- 미니 팀 프로젝트: 기초 프로그래밍을 활용한 간단한 콘솔/웹 애플리케이션 제작
- 목적: 협업 도구(Git) 사용법과 팀 개발 프로세스 체험

### 2학년
- 캡스톤 준비 프로젝트: 소단위 팀으로 실제 문제를 정의하고 프로토타입 개발
- 소프트웨어개발과: 웹 서비스 또는 앱 개발 프로젝트
- 스마트IoT과: 센서 데이터 수집·시각화 프로젝트

### 3학년
- 산학연계 캡스톤: 기업 협력사가 제시한 실제 과제를 해결
- 대표 과제 예시:
  - (주)테크브릿지 — 사내 예약 관리 웹 시스템 고도화
  - 스마트센서랩 — 실내 환경 모니터링 IoT 대시보드
  - 데이터피아 — 학습 데이터 파이프라인 자동화 도구

## 프로젝트 산출물
- 모든 실무 프로젝트는 소스코드, 발표자료, 시연 영상을 산출물로 제출한다.
- 3학년 캡스톤은 교내 발표회에서 심사를 거쳐 우수작을 선정한다.
